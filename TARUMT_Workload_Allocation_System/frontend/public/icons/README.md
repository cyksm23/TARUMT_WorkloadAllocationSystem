# Icon attribution

`auto-assign-white.png` is a white recolour of the user-provided
`Information System/auto-assign-icon-.png`, with its original alpha channel preserved.

- **Icon:** Auto Assign, #682368
- **Creator:** Mohamed Riyaz Ali
- **Source:** https://thenounproject.com/icon/auto-assign-682368/
- **Licence:** Creative Commons Attribution 3.0 (CC BY 3.0)
- **Licence URL:** https://creativecommons.org/licenses/by/3.0/
- **Modification:** black artwork recoloured white; no change to the shape or transparency.

The application also uses this local PNG as an alpha mask so the same artwork
can inherit the surrounding text colour, including white on blue buttons.
